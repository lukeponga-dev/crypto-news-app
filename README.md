# ⚡ CryptoPulse | Real-time Crypto News & Market Data

CryptoPulse is a premium, high-performance web application designed for cryptocurrency enthusiasts. It provides real-time news aggregation and live market data in a stunning, mobile-optimized interface.

![CryptoPulse Preview](https://images.unsplash.com/photo-1621761191319-c6fb62004040?q=80&w=1200&auto=format&fit=crop)

## ✨ Features

- **Live News Feed**: Real-time articles aggregated from over 50+ crypto news sources via CryptoCompare.
- **Market Overview**: Dynamic price ticker for top assets (BTC, ETH, SOL, etc.) with 24h performance tracking.
- **PWA Ready**: Fully installable as a Progressive Web App with offline support via Service Workers.
- **Premium UI/UX**: 
  - Glassmorphism design system.
  - Interactive radial mesh gradients.
  - Shimmering animated borders and micro-interactions.
- **Responsive & Mobile-First**: Optimized for everything from desktop monitors to smartphones.
- **Smart Filtering**: Filter news by category or search instantly through the latest headlines.

## 🚀 Tech Stack

- **Frontend**: Vanilla JavaScript (ES6+), HTML5, CSS3.
- **Build Tool**: [Vite](https://vitejs.dev/) for lightning-fast development and optimized production builds.
- **Design**: Pure CSS with backdrop-blur, custom animations, and responsive grid systems.
- **Data Source**: [CryptoCompare API](https://min-api.cryptocompare.com/).

## 🛠️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd crypto-news-app
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables:
   Create a `.env` file in the root directory and add your CryptoCompare API key:
   ```env
   VITE_API_KEY=your_api_key_here
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.

## 📱 Mobile Installation (PWA)

To install CryptoPulse on your mobile device:
1. Open the app in your mobile browser.
2. Select **"Add to Home Screen"** from your browser's menu (Share button on iOS, Three dots on Android).
3. The app will now appear on your home screen with a native-like experience.
